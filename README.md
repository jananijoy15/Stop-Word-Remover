🧹 Stop Word Remover

Stop Word Remover is a simple web-based Text Analysis application that removes common words from a given text to make the content more suitable for further text processing and NLP tasks.

Live Application Link 
https://jananijoy15.github.io/Stop-Word-Remover/

✨ Features

- 📝 Enter or paste text
- 🧹 Remove common stop words
- 📊 Count original words
- 🔢 Count remaining words
- ❌ Count removed words
- 📄 Display processed text
- ⚡ Fast text processing using JavaScript
- 📱 Mobile-friendly responsive interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Use

1. Open the application in a web browser.
2. Enter or paste text into the text area.
3. Click the Remove Stop Words button.
4. The application identifies common stop words.
5. The stop words are removed from the text.
6. The processed text and word statistics are displayed.

💡 Example

Input:

The artificial intelligence system is used in the healthcare industry.

Output:

artificial intelligence system used healthcare industry

📊 Analysis

Feature| Description
Original Words| Total words before processing
Remaining Words| Words left after removing stop words
Removed Words| Number of stop words removed
Processed Text| Text after stop-word removal
